1. نبذة عن المشروع

TALID منصة ذكية لإدارة ومتابعة عمليات التجارة الإلكترونية، تستهدف مساعدة أصحاب المتاجر على متابعة المنتجات والطلبات والأسواق والأرباح والتسويق من لوحة تحكم موحدة.

تستهدف المنصة العمل في الأسواق التالية:

- مصر
- المملكة العربية السعودية
- الإمارات العربية المتحدة
- سلطنة عُمان
- العراق

2. أهداف المنصة

- متابعة المنتجات والأسعار.
- إدارة ومتابعة الطلبات.
- متابعة الأسواق المستهدفة.
- تحليل المبيعات والأرباح.
- متابعة الحملات التسويقية.
- إدارة التكاملات مع منصات التجارة الإلكترونية.
- توفير تقارير تشغيلية وإدارية.

3. المنصات المستهدفة للتكامل

Taager

منصة البيع والتوريد والشحن والتحصيل، وفق الخدمات والصلاحيات المتاحة للحساب.

EasyOrders

منصة إنشاء صفحات الهبوط واستقبال الطلبات وإرسالها إلى منظومة البيع.

ملاحظة: تفعيل أي تكامل يتطلب التحقق من واجهات API الرسمية والصلاحيات المتاحة، ولا يُعتبر الاتصال فعالًا لمجرد وجود ملفات التكامل داخل المشروع.

6. إعداد المشروع

1. استنساخ مستودع المشروع من GitHub.
2. إعداد مشروع Supabase.
3. مراجعة ملفات قاعدة البيانات وتنفيذ التحديثات بالترتيب.
4. إعداد إعدادات الاتصال في ملف "config.js" محليًا.
5. نشر واختبار وظائف Edge Functions.
6. اختبار تسجيل الدخول والصلاحيات.
7. اختبار واجهة المستخدم والتكاملات.

لا تضع مفاتيح سرية أو كلمات مرور داخل مستودع GitHub العام.

7. الأمان

- استخدام Supabase Authentication.
- تطبيق Row Level Security (RLS).
- التحقق من صلاحيات المستخدم.
- حفظ المفاتيح السرية في متغيرات البيئة.
- تسجيل العمليات المهمة ومراجعتها.

8. حالة المشروع

المشروع قيد التطوير والاختبار.

وجود ملفات الواجهة وقاعدة البيانات ووظائف التكامل لا يعني اكتمال التشغيل الفعلي. يجب اجتياز اختبارات الاتصال والصلاحيات والطلبات قبل الانتقال إلى التشغيل التجاري.
